I'm Joe Yuen, a developer focused on the intersection of software and hardware. My main interests are embedded software, firmware, hardware systems, and accelerating workloads at the edge.

## What I'm Exploring

- **Embedded software and firmware**: low-level C/C++, device bring-up, peripherals, drivers, and real-time constraints.
- **Hardware systems**: microcontrollers, sensors, interfaces, debugging tools, and board-level thinking.
- **Edge acceleration**: CUDA, parallel computing, embedded AI, and performance-aware software design.
- **Systems debugging**: reading datasheets, tracing behavior, measuring performance, and understanding failure modes.
